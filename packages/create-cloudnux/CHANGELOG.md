# create-cloudnux

## 0.2.0

### Minor Changes

- [#23](https://github.com/cloudnux/cloudnux/pull/23) [`3922866`](https://github.com/cloudnux/cloudnux/commit/392286669aac571684ee0b7c7d8f219444c4af86) Thanks [@minawalphonce](https://github.com/minawalphonce)! - Add `create-cloudnux` scaffolding CLI. Running `yarn create cloudnux <project-directory>` (or `npx create-cloudnux`) prompts for a project name and cloud provider, scaffolds a new Cloudnux project from the matching template, and optionally runs `yarn install`.
